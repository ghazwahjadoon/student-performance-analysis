Student Performance Analysis

A beginner data analysis project built with Python using Pandas, NumPy, and Matplotlib.

Project Overview

This project analyzes a student performance dataset to identify patterns between study habits, attendance, previous academic performance, sleep hours, and final scores.

Technologies Used
Python
Pandas
Matplotlib
Analysis Performed

The project includes:

CSV data loading
Initial dataset exploration
Missing value detection
Missing value handling using median values
Duplicate detection and removal
Invalid data detection
Basic statistical analysis
Group analysis by gender
Top student identification
Correlation analysis
Data visualization
Visualizations

The project generates:

Final score distribution histogram
Study hours vs final score scatter plot
Average final score by gender
Average study hours by gender
Final score distribution by gender
Correlation matrix visualization
Dataset

The dataset contains student-related information such as:

Student ID
Gender
Study Hours
Attendance
Previous Score
Sleep Hours
Final Score
How to Run

Clone the repository:

git clone  https://github.com/ghazwahjadoon/student-performance-analysis.git

Open the project folder:

cd student-performance-analysis

Install the required libraries:

pip install pandas matplotlib

Run the project:

python main.py
Learning Goal

This project was created as a hands-on exercise to practice data analysis and visualization using Python, Pandas, NumPy, and Matplotlib.
